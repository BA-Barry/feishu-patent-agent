# 从这里开始

这份交付包用于两件事：在任意电脑的 Codex 中运行飞书专利 Agent，以及完成飞书 AI 绝活大会投稿。

## 你只需要按这个顺序做

1. 阅读外层的 `使用说明.md`，在准备录屏的电脑上安装产品。
2. 使用 `default` 配置该电脑上的第一个飞书账号，并完成两次扫码：应用配置、个人账号 OAuth。
3. 在 Codex 中打开目标项目并新建任务，创建匿名 Demo 项目。
4. 使用 `Demo匿名素材.md` 作为演示输入，不要使用未公开的真实发明。
5. 按 `三分钟Demo脚本.md` 录制 2 分 40 秒至 2 分 55 秒的实机视频。
6. 按 `社媒发布文案模板.md` 发布到小红书、抖音、B站或视频号，必须带 `#飞书AI绝活大会`。
7. 打开 `比赛投稿填写模板.md`，补齐所有 `【待填写】`，再粘贴到投稿表单。
8. 用 `提交清单.md` 做最终核对，并在 8 月 28 日 18:00 前提交。

## 新电脑最短安装流程（Windows）

```powershell
# 1. 解压内层产品 ZIP 后，进入产品目录
# 2. 安装到准备在 Codex 中打开的项目
powershell -ExecutionPolicy Bypass -File .\install-windows.ps1 -ProjectRoot "D:\飞书专利Demo"

# 3. 新电脑上的第一个飞书账号使用 default
powershell -ExecutionPolicy Bypass -File .\setup-feishu-account-windows.ps1 -Profile default
```

完成后，用 Codex 打开 `D:\飞书专利Demo` 并新建任务。输入：

```text
开始发明专利。飞书账号 profile 是 default。请先创建项目键 PAT-DEMO-001，项目名称为“防烫保温杯匿名演示”，然后读取我提供的匿名技术材料，并把项目状态、待确认事项和阶段成果写回飞书。
```

## 哪些内容必须由你本人完成

- 参赛人姓名或昵称、联系方式、飞书账号信息。
- 社交平台账号、视频链接和实际发布时间。
- 投稿表单入口和提交成功截图。
- 如需公开产品包或文档，设置网盘/GitHub/飞书云盘分享链接和访问权限。
- 录屏时确认画面中没有真实姓名、App ID、令牌、聊天对象或未公开专利材料。
